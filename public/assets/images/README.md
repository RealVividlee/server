# Site Images

Place website image assets in this folder.

Current files were imported from previously hardcoded remote image URLs so pages can serve images locally.
Replace any file here with your own image while keeping filenames, or update `<img src>` paths in HTML.

## Adding more images

1. Drop new files into `public/assets/images/` (for example: `gallery-your-project-1.jpg`).
2. Update the relevant page HTML to point to the new file path, e.g.:
   - `<img src="assets/images/gallery-your-project-1.jpg" alt="Your project photo" />`
3. Deploy the changed files and hard-refresh your browser to clear cache.

Tip: keep filenames lowercase with dashes and use descriptive `alt` text.
